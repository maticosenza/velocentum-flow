## Por qué quedó como nota

Este archivo y `.claude/SESSION_HANDOFF.md` eran **byte a byte idénticos**: el
mismo contenido vivía duplicado en dos rutas, con el riesgo de que una de las
dos se actualizara y la otra quedara mintiendo. Se verificó que la copia de
`.claude/` conserva toda la información útil —mismo SHA-256— antes de
reemplazar esta por la remisión.

`.claude/SESSION_HANDOFF.md` es la única versión que se mantiene. Cualquier
actualización del estado de V3 va allí, no acá.
